# SU Dynamic Cover Page Generator 🎓

A simple, fast, and fully responsive web tool designed for the students of **Sonargaon University (SU)**. This tool allows students to easily generate and download perfectly formatted, print-ready A4 cover pages for their lab reports, assignments, and projects.

## 🌐 Live Demo
[Click here to use the Generator](https://your-username.github.io/su_cover_page/) 
*(Note: Replace `your-username` with your actual GitHub username)*

## ✨ Features
* **Live Preview:** Type your details in the form and see the cover page update instantly.
* **Responsive Design:** Works smoothly on both desktop and mobile devices.
* **Print-Ready A4 Size:** Generates a perfect A4 size layout without any extra margins or bleeding.
* **One-Click PDF:** Directly save the generated cover page as a PDF file using the browser's native print function.
* **No Server Needed:** Fully frontend application built with pure HTML, CSS, and Vanilla JavaScript.

## 🚀 How to Use
1. Open the live website.
2. Fill in the form with your Report Type, Course, Teacher, and Student details.
3. Click on the **"Download / Save as PDF"** button.
4. In the print dialog, set the paper size to **A4**, Margins to **None/Default**, and enable **Background Graphics** (if needed for the blue banner).
5. Click **Save** to get your PDF!

## 🛠️ Technologies Used
* HTML5
* CSS3 (Flexbox, Media Queries, `@page` Print Media)
* Vanilla JavaScript (DOM Manipulation)
